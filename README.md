# Plastinka.com — парсер каталога винила

Один файл, без подготовки: собирает каталог виниловых пластинок с
[plastinka.com/lp](https://plastinka.com/lp) в таблицу Excel (xlsx) и CSV.

```bash
python plastinka_parser.py
```

## Что делает

1. **Ставит зависимости сам** — `httpx`, `lxml`, `cssselect`, `openpyxl`
   (в текущее окружение, с откатом на `--user` / `--break-system-packages`).
2. **Берёт список карточек из `sitemap.xml`** сайта — не листает пагинацию
   листинга (она запрещена в `robots.txt` правилом `Disallow: /*?`).
3. **Обходит карточки** `/lp/item/...` вежливо: 3 потока, пауза 0,5 с,
   ретраи с бэкоффом, автопауза при 403/429/503.
4. **Пишет `catalog.jsonl` построчно** — прогресс не теряется, повторный
   запуск продолжает с места остановки (дедупликация по `id` карточки).
5. **Собирает `Каталог_винила_Plastinka_<дата>.xlsx`** — лист «Каталог»
   с автофильтром и лист «Сводка» (суммы, скидки, распределения), плюс CSV.

## Данные по каждой пластинке

| Поле | Источник |
|---|---|
| Исполнитель, альбом, год, страна, лейбл, стиль | блок характеристик карточки |
| Тип (оригинал / переиздание), состояние, размер | там же |
| **Цена, ₽** | `meta[itemprop=price]` (schema.org Offer) |
| **Было, ₽** | зачёркнутая цена `.prev-price` |
| **Скидка, ₽ и %** | расчёт |
| Наличие, примечания, ссылка на карточку, ссылка на обложку | карточка |

Пример результата — `sample_output.csv` (5 строк).

## Ключи

```bash
python plastinka_parser.py --limit 50        # проверка на 50 карточках
python plastinka_parser.py --workers 3 --delay 0.5
python plastinka_parser.py --max-minutes 30  # остановиться и собрать файлы
python plastinka_parser.py --out ./data      # куда писать результаты
```

`Ctrl+C` безопасен: собранное сохраняется, xlsx/csv собираются сразу.
Повторный запуск догоняет остаток.

## Производительность (замеры)

- ~1,8–2,1 карточки/с при 3 потоках и паузе 0,5 с;
- полный каталог (≈6 500 карточек) — около 55 минут;
- ошибок на 3 900 запросах — 0.

## Правовая оговорка

Код публикуется для анализа публично доступных данных. Перед использованием:

- `robots.txt` сайта соблюдается: обходятся только разрешённые пути
  (`/lp/item/...`) и опубликованный сайтом `sitemap.xml`; пагинация листинга
  (`?page=`) не обходится;
- авторизация, капчи и персональные данные не затрагиваются;
- тексты описаний, фотографии и товарные знаки принадлежат Plastinka.com —
  скрипт сохраняет только ссылки на изображения, а не сами файлы;
- собранные данные — чужая база; публиковать саму выгрузку или использовать её
  в коммерческих целях без разрешения правообладателя не следует;
- будьте вежливы к сайту: не снижайте `--delay`, не поднимайте `--workers`
  без необходимости.

Перед публикацией результатов сверьтесь с правилами сайта
(<https://plastinka.com/terms>) и, при коммерческом использовании, спросите
разрешение у владельца.
